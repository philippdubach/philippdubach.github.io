## Phase 1 -- SERP Analysis

### 1. GPT-5.6 Sol reasoning effort

- **Format dominance:** Official model guidance, reasoning-effort guides, benchmark tables, and practitioner tests.
- **Site types ranking:** OpenAI, Artificial Analysis, technical publishers, model-comparison sites, and Reddit.
- **Content freshness:** Extremely high. Most visible results are from July or August 2026.
- **Common headings/sections:** Available effort levels, task selection, latency, cost, benchmarks, coding use cases, and when to escalate.
- **Gap:** Official guidance recommends choosing the lowest setting that passes, but few pages quantify total working time across every Sol effort level. Many third-party guides repeat benchmark numbers without adding original analysis.
- **SERP features:** Direct-answer snippets, comparison tables, forum discussions, and video guides. Stable People Also Ask output was not exposed, so question demand was inferred from recurring headings and related searches.

### 2. GPT-5.6 Sol High

- **Format dominance:** Model cards, benchmark pages, comparison tools, news explainers, and practitioner reports.
- **Site types ranking:** OpenAI, Artificial Analysis, API gateways, model directories, and community forums.
- **Content freshness:** Extremely high because the configuration launched recently.
- **Common headings/sections:** Intelligence, speed, price, context, coding performance, and comparisons with other reasoning levels.
- **Gap:** Results report High as one row in a larger table. Few explain why a user would select High rather than Medium, Xhigh, or Max for interactive work.
- **SERP features:** Model-summary panels, benchmark snippets, comparison tables, and discussion results.

### 3. GPT-5.6 Sol Fast mode

- **Format dominance:** Official product documentation, API how-to pages, pricing tables, and launch news.
- **Site types ranking:** OpenAI dominates, followed by API platforms, developer publications, and community discussions.
- **Content freshness:** Extremely high after Priority processing was renamed Fast mode on July 30, 2026.
- **Common headings/sections:** Speed improvement, token prices, `service_tier`, rate limits, latency targets, and suitable workloads.
- **Gap:** Official documentation explains the service. It does not measure the value of avoiding a human context switch or show how Fast mode interacts with reasoning-effort choices.
- **SERP features:** Official FAQ snippets, pricing tables, API syntax, and launch-news modules.

### 4. GPT-5.6 Sol Max vs Xhigh

- **Format dominance:** Practitioner benchmarks, effort-selection guides, community comparisons, and model-table tools.
- **Site types ranking:** Specialist blogs, model directories, benchmark sites, and Reddit.
- **Content freshness:** High; nearly all useful results were published within the last month.
- **Common headings/sections:** Pass rate, latency, cost, failed tasks, when Max regresses, and escalation policies.
- **Gap:** Results often use one narrow coding benchmark. The post uses the same nine-evaluation intelligence suite across every configuration and makes the snapshot date explicit.
- **SERP features:** Tables, charts, direct recommendations, and discussion threads.

### 5. GPT-5.6 Sol vs Claude Opus 5

- **Format dominance:** Head-to-head comparisons, benchmark tables, pricing explainers, videos, and community experience reports.
- **Site types ranking:** Training publishers, comparison sites, technology media, YouTube, and Reddit.
- **Content freshness:** Very high after both July 2026 releases.
- **Common headings/sections:** Coding benchmarks, abstract reasoning, context window, API price, speed, and which model to choose.
- **Gap:** Most comparisons focus on raw benchmark wins. The post separates interactive time budgets from the upper intelligence frontier and explains why a lower-scoring configuration can be more productive.
- **SERP features:** Comparison snippets, FAQ answers, tables, video results, and forum threads.

The post's strongest advantage is the original cross-configuration analysis:

- 22 OpenAI and Anthropic configurations use the same nine evaluations.
- Four original charts compare intelligence, first-token wait, output speed, and total working time.
- The post states the snapshot date, which protects a fast-changing comparison.
